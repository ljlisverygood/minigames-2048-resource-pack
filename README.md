# MiniGames 2048 Resource Pack

Public download host for the MiniGames 2048 digit-display resource pack.

Use the direct HTTPS URL below in the plugin configuration:

```yaml
games:
  2048:
    resource-pack:
      url: "https://raw.githubusercontent.com/ljlisverygood/minigames-2048-resource-pack/main/minigames-2048.zip"
      sha1: "b891ef84f74a73a3bb6eb9ce29c82dec3a917414"
```

The pack supports Java Edition 1.21 through 1.21.11: it contains the legacy item override for 1.21–1.21.3 and the current item model definition for 1.21.4+.

It overrides only `PAPER` items using MiniGames' CustomModelData values, so ordinary paper and concrete retain their vanilla appearance.
