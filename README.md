# MiniGames 2048 Resource Pack

Public download host for the MiniGames 2048 digit-display resource pack.

Use the direct HTTPS URL below in the plugin configuration:

```yaml
games:
  2048:
    resource-pack:
      url: "https://raw.githubusercontent.com/ljlisverygood/minigames-2048-resource-pack/main/minigames-2048.zip"
      sha1: "71a8d8296ec69194ddb196f418eb3a0c47750726"
```

The pack overrides only `PAPER` items using MiniGames' CustomModelData values, so ordinary paper and concrete retain their vanilla appearance.
